# 数据与隐私说明

[English](privacy.en.md) · [返回 README](../README.md)

本文说明当前仓库的实际数据处理方式。自行部署的站点由部署者管理；部署者增加的统计、代理、日志或其他服务，需要另行向使用者说明。

## 公开体验站

[在线体验](https://luojiedev.github.io/yuvo/)由 GitHub Pages 托管，只提供本机体验：

- 账本、流水、分类、账户、预算、订阅和选择的图片保存在当前浏览器的独立体验数据库中，不会上传到账本服务器。
- 体验构建会阻止应用 API 请求；页面同时使用 `connect-src 'none'` 限制网络连接。账号登录、家庭共享、云同步、自动汇率和系统通知不可用。
- 体验站不注册 Service Worker，不提供 PWA 离线安装。重新加载页面需要网络，已经保存的体验数据会保留在浏览器中。
- 网页及静态资源请求仍会发送给 GitHub Pages。托管平台可按其自身规则处理访问 IP、浏览器信息等请求数据。
- 体验站使用 `swift-ledger:demo-v1` 数据库，不读取正常版本的账号数据库，也不检查或迁移旧版账本。
- 浏览器存储以站点来源隔离，路径本身不是安全边界；同一来源下的其他应用可能共享浏览器存储权限。

体验数据没有云端副本。清理站点数据、使用隐私浏览、浏览器回收存储或更换设备，都可能导致数据无法恢复。请通过“我的 → 导入与导出”保存 JSON 备份。

## 自行部署版本的数据位置

| 数据 | 本机 | 部署者的云端 |
| --- | --- | --- |
| 账本、流水、分类、账户、预算、订阅 | IndexedDB 保存本地副本 | 登录并接入账号后同步到 D1 |
| 图片附件 | IndexedDB 保存原文件或已下载的副本 | 登录同步时上传到 R2，D1 保存附件元数据 |
| 待同步操作、同步游标、恢复记录 | IndexedDB | 服务端另行保存变更、版本及幂等处理记录 |
| 登录会话 | IndexedDB 保存访问令牌及会话信息 | D1 保存令牌哈希、有效期及撤销状态 |
| 账号与设备信息 | 当前会话及设备标识 | D1 保存用户名、展示名称、设备标识等 |
| 密码 | 输入时由页面处理，不写入账本备份 | 服务端保存随机盐及 PBKDF2-SHA-256 派生值 |
| 界面偏好、最近账本和汇率缓存 | localStorage | 相应业务设置按具体功能同步 |
| 应用外壳与静态资源 | Service Worker Cache Storage | 站点托管资源 |

未登录时，账本内容保存在本机，不会自动上传。完整版本仍会请求同站点的启动文案、初始化状态等接口；切换外币时可请求参考汇率。

登录时可以选择将本机账本接入账号，或稍后从账本管理中接入。接入后，账单、附件和相关设置会按照账号与账本权限同步。仓库作者不会仅因你使用源码，就获得你部署实例中的数据；部署者及有云资源访问权限的人员能够管理其 D1、R2 和运行日志。

## 账号、共享与访问边界

- 每个账号使用独立的本地数据库。退出登录会清除本机该空间的会话并切回访客空间，已缓存数据和待同步操作会保留。
- 本地账号隔离是应用层的访问控制，不是数据库加密。能访问浏览器配置、开发者工具或设备文件的人，可能读取本地数据。
- 私人账本与家庭账本分开授权。家庭成员可按权限访问共享账本，其中包括流水、描述、附件和记录人名称。
- 当前实现没有端到端加密。HTTPS 保护网络传输，服务器仍需读取账本内容完成同步、查询和通知处理。
- 请为自己的部署使用 HTTPS，保护设备和云账号，并仅向可信的人发放邀请。

## 外部服务、通知与日志

- 完整版本运行于部署者配置的 Cloudflare Workers、D1、R2 和 Images。托管平台处理站点请求，其日志、存储位置、保留策略和备份由部署者及平台配置决定。
- USD/CNY 参考汇率由 Worker 向 Frankfurter 请求，查询参数包含币种对，不需要发送账单金额、描述、账号或附件。用户也可手动填写汇率。
- 系统通知需用户主动授权。D1 保存推送端点、订阅密钥及用户和设备关联；消息经浏览器或操作系统的推送服务投递。
- 家庭通知正文会包含记录人展示名称、收支类型和分类，点击链接包含账本及流水标识。系统可能在锁屏显示通知内容，请根据设备设置控制预览。
- 代码包含浏览器调试日志和服务端结构化日志，可能记录请求标识、用户/设备/实体标识、操作状态和错误。提交 Issue 或分享日志前，应移除令牌、邀请、推送地址和私人账目。
- 当前应用代码未接入第三方广告、访问统计或行为追踪 SDK；这不代表托管平台不处理网络请求信息。

## 删除、保留与恢复

- 删除流水会先记录删除状态，再通过同步传播；这不等于立即擦除全部服务器记录、同步历史、附件和备份。
- 当前没有完整的账号注销、数据彻底擦除或附件自动回收功能。需要删除云端数据时，请联系该部署实例的管理员，由其处理数据库、附件、备份和日志。
- 退出账号、卸载桌面图标与清除站点数据的效果不同；退出不会删除账本，移除图标也不能保证清除了浏览器中的数据。
- 清理站点数据会移除本地账本、会话及缓存。只有已成功同步且仍有访问权限的数据可从云端恢复；未同步内容需要事先导出。
- 更换域名或站点来源后，浏览器不会自动把旧来源的本地数据交给新来源。迁移前请完成同步并保存 JSON 备份。

## 导入与导出

- JSON 备份包含当前账本、预算、账户、分类、流水、订阅和本机已有图片；缺失附件需要先下载补齐。
- CSV 用于流水交换，不包含完整账本结构和图片。
- 备份不包含密码、会话令牌、邀请令牌和通知订阅，但会包含账单描述、金额、记录人及附件等私人内容。
- 导出文件未加密，请保存在可信位置；把文件上传到其他服务后，其后续处理由该服务决定。
- 详细格式及幂等导入规则见[导入、导出与恢复设计](import-export.md)。
